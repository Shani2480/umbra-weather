# Weather Underground Icons

SVG icons from https://github.com/manifestinteractive/weather-underground-icons
(preview: https://peter.build/weather-underground-icons/).
Icons designed by Ashley Jager (http://www.ajager.com/#/weather-underground/).
Repository code is available under MIT and GPL; see LICENSE.

Variants: `white`, `black`, `solid-white`, `solid-black` (as named upstream).
Night icons are prefixed `nt_`.
